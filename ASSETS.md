# Asset Requirements

To complete the app setup, you'll need to add the following image assets to the `assets/` directory:

## Required Assets

1. **icon.png** (1024x1024)
   - Main app icon

2. **splash.png** (1284x2778)
   - Splash screen image
   - Background: #0a0a0a

3. **adaptive-icon.png** (1024x1024)
   - Android adaptive icon

4. **favicon.png** (48x48)
   - Web favicon

5. **notification-icon.png** (96x96)
   - Notification icon (white on transparent)

## Quick Setup

You can create placeholder assets with any image editor or use online tools:

1. Create a 1024x1024 image with the app logo/name
2. Export variations for each required size
3. Place them in the `assets/` folder

## Temporary Workaround

If you want to test without custom assets, you can:
1. Use any PNG images with the correct dimensions
2. Or temporarily comment out the asset paths in `app.json`
